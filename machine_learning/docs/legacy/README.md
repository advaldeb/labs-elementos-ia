# Archivos legacy conservados

`clustering-requirements-original.txt` conserva sin editar el manifiesto hallado en `01 clustering/requirements.txt`. Contenía una lista extensa y fijada de paquetes de varios dominios, incluidos componentes ajenos a clustering, por lo que no se usa como manifiesto instalable del curso. Las dependencias directas identificadas se consolidaron en `pyproject.toml` y `requirements.txt` de la raíz.

Los dos ZIP originales se conservaron en `data/external/legacy/`; ambos son archivos ZIP válidos de 22 bytes sin miembros. No se extrajeron ni reemplazaron.
