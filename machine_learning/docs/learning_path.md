# Ruta de aprendizaje

La secuencia va de describir estructura en los datos a construir modelos predictivos y después integrar esos conceptos en problemas temporales y de segmentación.

1. **Clustering:** K-means, agrupamiento jerárquico y mezclas gaussianas introducen distintas nociones de semejanza y estructura latente.
2. **Reducción de dimensionalidad:** PCA y análisis factorial exploran representaciones compactas y factores no observados.
3. **Modelos lineales:** regresión lineal establece una referencia interpretable para problemas supervisados.
4. **Regularización:** Ridge, Lasso y Elastic Net muestran cómo controlar complejidad y tratar predictores correlacionados.
5. **Modelos basados en árboles:** árboles, Random Forest, Gradient Boosting y XGBoost amplían las formas funcionales y las estrategias de ensamble.
6. **Clasificación:** módulo reservado para una futura ampliación del curso.
7. **Series de tiempo:** regresión espuria, rezagos distribuidos, Holt-Winters, ETS, Prophet y SARIMA introducen estructura temporal y pronóstico.
8. **Selección y evaluación de modelos:** módulo reservado para una futura síntesis de validación y comparación.
9. **Aplicaciones integradas:** segmentación de clientes reúne clustering, reducción de dimensión, preparación de datos e interpretación.

Los módulos reservados describen la arquitectura prevista, no contenido existente. El orden operativo de los notebooks está indicado por su numeración local; el análisis temporal conserva además un laboratorio histórico de pronóstico eléctrico.
