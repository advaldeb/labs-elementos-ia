# Datos

Los veintisiete laboratorios generan conjuntos pequeños y reproducibles dentro de sus notebooks. No se necesita red, credenciales, datasets descargados ni pesos preentrenados para cumplir el objetivo principal.

Las tareas sintéticas aíslan mecanismos como XOR, gradiente, convolución o atención; no se presentan como evidencia de rendimiento en datos reales. Las particiones se definen antes del ajuste y las transformaciones aprendidas se estiman solo con train. No se versionan datos grandes ni derivados regenerables.

Al añadir un recurso externo, registra aquí URL, autor/fuente, licencia, fecha de acceso, columnas y preparación; documenta una alternativa local que permita cumplir el objetivo si la descarga falla.
