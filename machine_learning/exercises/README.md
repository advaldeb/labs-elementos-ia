# Ejercicios

Espacio reservado para ejercicios guiados, prácticas independientes y desafíos. Los módulos siguen la misma organización temática que `notebooks/`; no se han copiado notebooks existentes ni creado ejercicios ficticios.

Los subdirectorios por tema están preparados para recibir archivos con nombres técnicos en inglés y enunciados pedagógicos en español.
